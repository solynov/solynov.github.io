Factur-X : qu'est-ce que c'est et comment en générer une

Factur-X est le format de facture électronique de référence en France pour les petites entreprises. Son gros atout : la facture reste lisible comme un PDF normal, tout en étant exploitable automatiquement par les logiciels. Voici le format expliqué simplement, et comment en produire une.

Un PDF lisible + des données structurées

Une Factur-X, c'est deux choses en un seul fichier :

La partie visible (PDF/A-3)

Le PDF de votre facture, tel que vous et votre client le voyez à l'écran ou à l'impression. Rien ne change de ce côté : c'est une facture lisible normalement.

La partie structurée (XML)

Un fichier XML intégré, invisible à l'œil, qui reprend les mêmes informations sous forme de données normalisées (norme européenne EN 16931). C'est ce que lisent automatiquement les logiciels et l'administration.

Factur-X est un format « hybride » franco-allemand. En France, c'est l'un des formats socles admis par la réforme (avec les formats XML purs UBL et CII).

Une vraie Factur-X, ouverte en deux

Voici la même facture vue des deux côtés. À gauche, le PDF que vous et votre client lisez normalement. À droite, le fichier XML embarqué à l'intérieur du même document : invisible à l'écran, il reprend les mêmes informations sous forme de données normalisées, lisibles automatiquement par les logiciels et l'administration. Pourquoi ce format plutôt qu'un PDF classique ?

✓

Conforme à la réforme

Un PDF classique ne suffit pas : c'est une image pour la machine. La partie XML de Factur-X est précisément ce qu'exige la réforme.

👁

Toujours lisible

Contrairement à un XML pur, Factur-X reste consultable comme un PDF ordinaire — pratique pour vous et vos clients.

⚙

Exploitable automatiquement

Les données structurées permettent le traitement automatique (comptabilité, contrôle, paiement) sans ressaisie.

Questions fréquentes

Qu'est-ce que le format Factur-X ?

Un format hybride : un PDF/A-3 lisible + un fichier XML de données structurées (EN 16931). Lisible par l'humain et exploitable par les machines.

PDF classique vs Factur-X ?

Le PDF classique est une image ; la Factur-X ajoute les données structurées qu'exige la réforme.

Comment en générer une ?

Avec un logiciel comme SOLYNOV, à partir de vos données — sans écrire le XML vous-même, avec vérification automatique.
