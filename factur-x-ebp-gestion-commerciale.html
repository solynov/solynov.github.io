Bridge, système par système

Produire des Factur-X depuis EBP Gestion Commerciale

Vous facturez avec EBP Gestion Commerciale et vous voulez des Factur-X sans migrer ni souscrire un abonnement de plus. EBP exporte bien ; Solynov Bridge lit ces exports et produit les factures électroniques à côté. Voici les commandes, et la façon de les automatiser.

Exporter depuis EBP Gestion Commerciale (Open Line)

Dans EBP Gestion Commerciale — ACTIV, PRO ou Élite — toute liste dispose d'un bouton « Exporter », et un assistant d'exports paramétrables produit des fichiers texte pour ce que les listes ne montrent pas. Trois exports, dans le dossier que Bridge surveille.

Clients et articles : le bouton « Exporter » de la liste

  1. Ouvrez la liste des clients (menu Ventes › Clients) puis celle des articles (Articles).
  2. Bouton Exporter dans la barre d'outils, ou clic droit sur la liste › « Exporter tout » (« Exporter la sélection » ne prend que les lignes cochées). Choisissez le format xls ; EBP propose aussi txt, html et xml.
  3. L'export reprend les colonnes de la vue. Avant d'exporter, affichez celles qu'il faut (SIRET, adresse, code postal, ville, n° de TVA intracom pour les clients ; référence, désignation, prix HT, TVA pour les articles) via l'éditeur de vue — ce qui n'est pas affiché n'est pas exporté. Enregistrez dans le dossier Bridge.

Autre voie, sans réglage de vue : Imports/Exports › Exportation de données, tables Clients, Contacts, Articles, Familles… en TXT ou CSV séparé par des points-virgules, un type de fichier à la fois. Bridge lit ces CSV tels quels.

Les lignes de factures : les exports paramétrables

La liste Ventes › Documents de vente, filtrée sur les factures, s'exporte comme les autres — mais avec une ligne par document. Pour le détail des articles, passez par l'assistant :

  1. Imports/Exports › Exports paramétrables (ou Outils › Exports paramétrables selon la version) : nouvel export, table des factures de vente.
  2. Indiquez le fichier de sortie dans le dossier Bridge, un filtre sur la période si vous voulez, puis « Tout exporter » (ou choisissez les champs : numéro, date, client, et les champs de ligne — article, quantité, prix unitaire HT, taux de TVA).
  3. Suivant, Suivant : le fichier texte, séparé par des points-virgules, est produit. Enregistrez le modèle d'export : c'est lui que vous rejouerez — ou que l'automatisation rejouera.
Selon la version, les champs de ligne d'une facture apparaissent dans le modèle sous un préfixe « Ligne — … ». S'ils manquent dans votre édition, l'aide en ligne EBP et votre revendeur sont les bonnes sources ; l'export se règle une fois, puis se rejoue en deux clics.

Automatiser

EBP n'a pas de planificateur d'export dans l'interface, mais le module SDK (fourni avec les versions récentes de Gestion Commerciale ; vérifiez auprès d'EBP pour la vôtre) ajoute une ligne de commande : l'application lancée avec /Gui=false /Export="C:\Exports\Factures.txt";SaleInvoices;"NomDuModèle" rejoue un modèle d'export paramétrable sans ouvrir de fenêtre. Placée dans le Planificateur de tâches Windows (chaque soir, ou toutes les heures), elle réécrit vos fichiers ; la génération automatique de Bridge produit ensuite les Factur-X. Votre revendeur EBP met cela en place en une demi-heure.

Ce que Bridge attend : trois tables, des colonnes nommées

Quel que soit l'outil d'origine, Bridge lit des tables — un fichier Excel (.xlsx, .xlsm) ou CSV par table, ou un seul classeur avec une feuille par table — avec les intitulés de colonnes sur la première ligne. Les noms de colonnes n'ont pas à être les siens : Bridge reconnaît « N° pièce », « Numéro », « Réf. facture »… et vous confirmez sa lecture une fois pour toutes.

Une facture par ligne ou une ligne d'article par ligne ? Une ligne d'article par ligne, avec le numéro de facture répété : c'est ce que la Factur-X exige (chaque ligne porte sa TVA). Si votre export ne donne qu'un total par facture, cherchez l'export des lignes — « détail des pièces », « lignes de documents » — c'est lui qu'il faut.

Ensuite, dans Bridge : trois gestes, la première fois seulement

  1. Données — indiquez le dossier où vos exports sont déposés. Bridge y lit vos tables et vous dit l'étape suivante.
  2. Production factures → « Tester la conformité avant génération » — premier temps, la validation des données : pour chaque champ de la facture électronique, la colonne où Bridge le lit ; vert reconnu, jaune à confirmer d'un coup d'œil, rouge à choisir dans la liste. Vous confirmez : c'est mémorisé. Second temps, ce qu'il reste à compléter : rouge obligatoire (la facture ne sort pas), jaune facultatif ; une liste des corrections par table, à garder ouverte pendant que vous corrigez dans votre gestion — jamais dans les exports, qui seront écrasés au prochain export. « Vérifier mes corrections » relit vos tables sans fermer la fenêtre.
  3. « Générer les factures » — les Factur-X (PDF/A-3 + XML) arrivent dans le dossier de sortie, rangées par année et par mois ; ce qui a déjà été produit n'est jamais régénéré. Puis, si vous voulez, Génération auto : Bridge relit le dossier à la fréquence choisie et produit les nouvelles factures sans que personne n'ouvre le logiciel.

Questions fréquentes

EBP propose sa propre facture électronique, pourquoi Bridge ?

Les offres EBP de facturation électronique sont liées à un abonnement et à leur plateforme. Bridge est l'alternative pour garder EBP Gestion Commerciale tel quel, produire les Factur-X localement, en achat unique, et transmettre par la plateforme de votre choix.

Quel format d'export choisir dans EBP : xls ou txt ?

Les deux conviennent. Le bouton « Exporter » d'une liste donne un xls direct ; l'exportation de données et les exports paramétrables donnent du texte séparé par des points-virgules, que Bridge lit comme un CSV. Ce qui compte, c'est que la première ligne porte les noms de colonnes.

Faut-il le module SDK pour utiliser Bridge ?

Non. Le SDK ne sert qu'à automatiser l'export par ligne de commande. Sans lui, vous rejouez le modèle d'export en deux clics à chaque lot de factures ; Bridge fait le reste, y compris la génération automatique.
